## 📋 Sobre

**DefaceMaker** é uma ferramenta educacional que gera páginas de deface com 5 estilos diferentes. Desenvolvido para **fins de estudo e conscientização em segurança cibernética**.

> ⚠️ **Aviso:** Esta ferramenta é exclusivamente para **fins educacionais** em ambientes controlados. O uso indevido é de total responsabilidade do usuário.

## 🚀 Instalação

### 1. Clone o repositório

```bash
git clone https://github.com/DoisPredoBeibe13/DefaceMaker.git
```

### 2. Entre na Pasta

```bash
cd DefaceMaker
```


### 3. Dê Permissão ao Setup

```bash
chmod +x defacemaker.py setup.sh
```

### 4. Executar o Instalador

```bash
sudo ./setup.sh
```


### 5. Usar o DefaceMaker

```bash
sudo python3 defacemaker.py
```
